## How to Install and Run

You will need Git and Python 3 installed on your computer. These instructions are for Mac or Linux.

First, open your terminal and copy the repository to your computer:

```bash
git clone https://github.com/rparks1-eng/git-github-basics-assignment.git
cd git-github-basics-assignment
```

Next, create a Python environment for this project and install the packages:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

You can read the Python notebook on GitHub without running anything.

To run the language model example, you will also need your own OpenAI API key saved as the `OPENAI_API_KEY` environment variable. Once that is set up, run:

```bash
python llm_call.py
```

Do not upload your API key to GitHub.
